# Kestrel Tenant Portal

Multi-tenant configuration workspace, prompt matrix, and conversation telemetry portal built with Vue 3, Vite, Tailwind CSS, and Vitest.

## Scripts

- `npm install` — Install dependencies
- `npm test` — Run unit and component test suite via Vitest
- `npm run build` — Build production bundle
- `npm run dev` — Start local development server
